# Base N Arithmetic
* ~over-simplification
	* long addition/subtraction where carry/borrow happens at N
	* 10 is in the base the arithemetic is done in

# Base N Addition
* $$N-1$$ is the max a number in Base N a digit can take
* Carry occurs at >= N
