# [Character Encodings]
* Humans use various writing scripts
    * Roman Letters: A-Z
    * Arabic Numerals: 0-9
    * Other Languages: 他の言葉
* Computers only know binary numbers
* How do we represent these writing scripts?
    * Attach a writing script (letter/symbol) to a specific numeric value

# Character Encoding
* A mapping of symbols to numeric values
* [ASCII] - American Standard Code for Information Interchange
    * Dominant English encoding
    * [ASCII Table] - 7-bit encoding
    * Basis for modern encodings

# Other Encodings
* [Extended ASCII] - Add 8th bit
* [ISO-8859] (Latin) - 8-bit encoding, E.g., Latin-1
* [Unicode] - Succeeds [ISO-8859], supports all the world's writing systems
    * UTF-8, UTF-16, UTF-32
* [EBCDIC] - 8-bit basic Latin encodings (non‑ASCII), primarily for IBM Mainframe
